
## Privacy Policy for Discord Application

**Effective Date:** October 13, 2026

This Privacy Policy dictates how this Discord application, developed by Santanu Sarkar ("the Developer"), collects, uses, and protects information when authorized and utilized within a Discord server.

### 1. Information Collection

The application only collects data necessary for its core functionality. When authorized in a server or interacted with, the following information may be collected:

* **Discord User IDs:** Used to identify users for permissions, cooldowns, or specific command interactions.
* **Guild (Server) IDs:** Used to store server-specific configurations and preferences.
* **Interaction Data:** Data provided directly through application commands (slash commands) and button interactions.
* **Message Content:** (If message intent is enabled and required) Processed strictly to trigger specific text-based commands and is not persistently stored unless required for a specific, user-requested feature.

### 2. Use of Information

The collected data is used exclusively to:

* Execute commands and provide the intended functionality of the application.
* Maintain and improve the stability and performance of the bot.
* Prevent abuse, spam, and ensure compliance with Discord's Developer Terms of Service.

### 3. Data Storage and Security

All collected data is stored securely. The Developer implements reasonable security measures to protect against unauthorized access, alteration, or destruction of this data. Data is retained only as long as necessary to provide the service.

### 4. Data Sharing and Disclosure

The Developer does not sell, trade, or otherwise transfer your identifiable information to outside parties. Data may be disclosed only if required by law or to comply with Discord's Terms of Service.

### 5. Data Retention and User Rights

* **Retention:** Server-specific data is retained while the application remains authorized in the server.
* **Deletion:** Server administrators can request the deletion of their server's data by kicking the bot from the server. Users can request the removal of their personal data (such as User IDs stored in databases) by contacting the Developer.

### 6. Changes to This Policy

This Privacy Policy may be updated periodically to reflect changes in functionality or legal requirements. Updates will be reflected by modifying the "Effective Date" at the top of this document.

### 7. Contact Information

If you have any questions, concerns, or requests regarding this Privacy Policy or your data, please contact the Developer, Santanu Sarkar, via your established support channels or GitHub repository.
